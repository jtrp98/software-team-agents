# Agent preamble

If you have shell tools, run `AGENTCLAUDE_CONTEXT_CMD` (or `sta context`) with `<your-role> --module <name> --phase <n>` for context, and read policies with `sta policy`. If not, `Grep` headings and `Read` offsets instead of running unavailable scripts. Never read whole directories. Use the module folder named by `_docs/status.md`; if none exists, work only on the user's ad-hoc request. Verify claims from current files, use dates supplied by the user, and keep handoffs concise: work done, evidence, blockers, and next owner. Do not invent an unstated business, design, or verification rule: record the gap and route it to its owner. See `CLAUDE.md` for the operating rules that always apply.
